# ?? Trademify VPS Deployment Guide

## Quick Start (One-Click)

```powershell
# Run as Administrator
cd C:\trademify\vps
.\quick-deploy.ps1
```

## ?? Available Scripts

| Script | Description |
|--------|-------------|
| `quick-deploy.ps1` | One-click production deployment |
| `install-service.ps1` | Install Windows Service (NSSM) |
| `setup-task-scheduler.ps1` | Install Task Scheduler tasks |
| `uninstall-service.ps1` | Complete cleanup |
| `start-services.bat` | Start services (interactive) |
| `stop-services.bat` | Stop all services |
| `check-status.bat` | View detailed status |

## ?? Deployment Options

### Option 1: Windows Service (NSSM) - Recommended

Best for production VPS. Starts before user login.

```powershell
.\install-service.ps1
```

Features:
- ? Runs as SYSTEM account
- ? Starts at Windows boot (before login)
- ? Auto-restart on crash (5 second delay)
- ? Log rotation built-in
- ? Fastest startup

### Option 2: Task Scheduler

Simpler setup with built-in watchdog.

```powershell
.\setup-task-scheduler.ps1
```

Features:
- ? Health check every 5 minutes
- ? Auto-restart on crash
- ? Daily restart at 3 AM for stability
- ? Log rotation at 4 AM
- ? 10-year duration configured

## ?? Management Commands

### Start/Stop

```powershell
# Windows Service
net start TrademifyAPI
net stop TrademifyAPI

# Task Scheduler
Start-ScheduledTask -TaskName "TrademifyBot"
Stop-ScheduledTask -TaskName "TrademifyBot"
```

### Check Status

```powershell
# Service status
sc query TrademifyAPI

# Task Scheduler status
Get-ScheduledTask -TaskName "TrademifyBot" | Select State

# Full status check
.\check-status.bat
```

### View Logs

```powershell
# Service logs (NSSM)
Get-Content C:\trademify\logs\trademify.log -Tail 100

# Task Scheduler logs
Get-Content C:\trademify\logs\watchdog.log -Tail 50
```

## ?? Security Notes

1. **Firewall**: Open port 8000 only if remote access needed
2. **MT5**: Keep MT5 terminal running for live trading
3. **VPS**: Use Windows Server for best stability

```powershell
# Open firewall port (if needed)
New-NetFirewallRule -DisplayName "Trademify API" -Direction Inbound -Port 8000 -Protocol TCP -Action Allow
```

## ? Uninstall

```powershell
# Remove everything
.\uninstall-service.ps1

# Keep logs
.\uninstall-service.ps1 -KeepLogs

# Force (no confirmation)
.\uninstall-service.ps1 -Force
```

## ??? Troubleshooting

### API Not Starting

```powershell
# Check if port is in use
netstat -an | findstr "8000"

# Check Python
C:\trademify\venv\Scripts\python.exe --version

# Manual test
cd C:\trademify\backend
..\venv\Scripts\activate.ps1
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000
```

### Service Won't Install

```powershell
# Check NSSM exists
Test-Path C:\trademify\nssm\nssm.exe

# Try Task Scheduler instead
.\setup-task-scheduler.ps1
```

### Bot Not Trading

1. Check MT5 is running
2. Check .env has correct MT5 credentials
3. Check API health: http://localhost:8000/health
4. Check bot status: http://localhost:8000/api/v1/bot/status

## ?? Tips for 10-Year Operation

1. **Use SSD**: Faster I/O for logs
2. **32GB+ RAM**: For long-term stability
3. **UPS**: Protect against power outages
4. **Windows Server**: Better for services
5. **Daily log monitoring**: Check watchdog.log
6. **Monthly VPS maintenance**: Windows updates
7. **Backup .env file**: Keep credentials safe
